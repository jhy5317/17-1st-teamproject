# 데이터 설명 및 폭염 취약도 분석 방법

## 1. 분석 목적과 단위

이 프로젝트는 대구광역시 150개 행정동을 서로 비교해 구조적으로 폭염에
더 취약한 곳을 찾는다. 지도 점수는 절대적인 재난 발생 확률이 아니라
동일 시점의 **상대 취약도**다. 구·군 자료는 같은 구·군의 행정동에
공통 적용하며, 대구 전체 단위 자료는 행정동 간 차이를 만들 수 없으므로
시간적 배경 설명에만 사용한다.

## 3. 상대 취약도 산식

점수에 사용하는 여섯 구성요소는 다음과 같다.

1. 불투수면 위험
2. 녹지 부족
3. 고령인구 민감도
4. 무더위쉼터 밀도 부족
5. 무더위쉼터 접근 부족
6. 그늘막 밀도 부족

원자료 값 `x`를 전체 150개 행정동의 최솟값과 최댓값으로 정규화한다.

`z = (x - min(x)) / (max(x) - min(x))`

값이 클수록 공급이 충분한 쉼터·그늘막 지표는 취약 방향을 맞추기 위해
`1 - z`를 사용한다. 모든 구성요소는 0~1이며 별도의 가중치를 주지 않는다.
행정동 `i`의 합계와 표시 점수는 다음과 같다.

`합계_i = Σ z_ij`

`상대 취약도_i = 100 × 합계_i / k_i`

`k_i`는 실제로 값이 있는 구성요소 수다. 일반 행정동은 6이고, 그늘막
원본이 없는 군위군 8개 행정동은 결측을 0으로 바꾸지 않고 나머지 5개
구성요소의 평균을 사용한다. 결과에는 구성요소 수와 자료 충족률을 함께
기록한다.

등급은 점수의 사분위수로 나눈다.

- 낮음: P25 미만
- 보통: P25 이상 P50 미만
- 높음: P50 이상 P75 미만
- 매우 높음: P75 이상

현재 결과의 경계값은 P25 52.84, P50 60.70, P75 64.82이며 원자료가
바뀌면 다시 계산된다.

## 4. 해석 시 주의사항

- 동일기여 방식도 하나의 분석 선택이며 객관적 진실을 뜻하지 않는다.
- 불투수면 위험과 녹지 부족의 상관계수는 0.9693이다. 요청에 따라 각각
  독립 지표로 합산했으므로 토지피복 영향이 중복 반영될 가능성을 함께
  설명해야 한다.
- 고령인구와 그늘막은 행정동보다 거친 공간 단위다. 행정동 자료가
  확보되면 교체하는 것이 바람직하다.
- 대구 전체 기온·특보·온열질환 자료는 어느 행정동에도 같은 값이
  적용되어 최소–최대 정규화가 불가능하거나 순위에 영향을 주지 않는다.
- 이 결과는 탐색과 우선 현장조사를 위한 상대 비교이며, 정책 확정 전
  표면온도·독거노인·저소득층·행정동 인구 자료와 현장 검증이 필요하다.
